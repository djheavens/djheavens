# Divine Heavens — GitHub Pages Portfolio

A responsive, red-accented personal portfolio inspired by the dark, terminal-like presentation of Blackbird Defence.

## Publish on GitHub Pages

1. Create a GitHub repository named **`YOUR-USERNAME.github.io`** (replace `YOUR-USERNAME` with your GitHub username).
2. Extract this ZIP file.
3. Upload the contents of this folder to the **root** of that repository. `index.html` must be at the root, not inside another nested folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site address will be `https://YOUR-USERNAME.github.io/`.

## Before publishing

- Confirm that you want your phone number, email address and CV publicly visible. A public portfolio makes these details accessible to anyone.
- Replace the résumé file in `assets/` if you update your CV. Keep the filename `Divine-Heavens-Resume.docx`, or update the download link in `index.html`.
- The website link `djheavens.com` and résumé contact details are reproduced from the supplied CV.
- The logo is included as `assets/eagle-logo.png`.
- This is a static site: no server, database, framework or paid hosting is required.

## Files

- `index.html` — page content and sections
- `styles.css` — responsive layout and red/black visual system
- `script.js` — mobile navigation
- `assets/` — eagle emblem and downloadable résumé
